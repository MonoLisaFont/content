Hi,

We spend a lot of time thinking about the small details in MonoLisa. It's interesting to see which ones someone else notices after living with the typeface for a while.

In [Typography News No. 71, Jectives takes a close look at MonoLisa Code and Text](https://www.youtube.com/watch?v=qGhrWv8vQCw&t=4327s). The host had been using them for almost two months, with Code in text editors and Text in Obsidian, the Linux interface, and the browser.

The MonoLisa section runs for about 29 minutes. Besides showing the fonts in everyday use, it explores the letterforms and OpenType features in Affinity. A few places you might enjoy:

- [Making MonoLisa your own (1:14:11)](https://www.youtube.com/watch?v=qGhrWv8vQCw&t=4451s): choosing features on the website and downloading a custom font for applications where those controls are harder to reach.
- [Looking closely at the letters (1:20:42)](https://www.youtube.com/watch?v=qGhrWv8vQCw&t=4842s): the bowed strokes in A, V, and W, the open C, and the thinking behind recognizable shapes at small sizes.
- [From Code to Text (1:29:42)](https://www.youtube.com/watch?v=qGhrWv8vQCw&t=5382s): how MonoLisa's character carries over into a proportional font for reading, writing, and interfaces.

We particularly enjoyed the attention given to MonoLisa Text. Seeing it used for everyday writing and across a desktop gives a different view of the family than a code specimen alone.

If the walkthrough makes you curious about a particular letter or setting, [try it in the online tester](https://www.monolisa.dev/tester).
